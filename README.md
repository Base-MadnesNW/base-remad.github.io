# База Знаний Безумия (madness-NW)

Интерактивный справочник по игре «Безумие»:
- 108 буйных (этажи A–O и донатный этаж $)
- 92 бизнеса с полными требованиями и расчётами до максимального уровня
- Интерактивная карта заначек
- 169 квестов (11 актуальных групп)
- Калькулятор W-мутагенов
- Адаптивный интерфейс для ПК (сетка в 2-3 колонки) и смартфонов

## Запуск через GitHub Pages
Репозиторий настроен для автоматической публикации через GitHub Pages.
В настройках репозитория: **Settings -> Pages -> Branch: main -> / (root) -> Save**.
